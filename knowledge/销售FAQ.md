# 4.8 可以给一个最简单的调用示例吗?

知识ID:KB-852cea59546e
产品:SmartTITU
版本:2026-10-08 v1
适用对象:customer
状态:source_based
来源:7.SmartTITU销售常见问题速查FAQ-20261008v1.pdf | PDF物理页:7

接口兼容 OpenAI Chat Completions 格式。将 <模型ID> 与环境变量 API_KEY 替换为已开通模型及实际密钥。
```bash
curl https://api.smarttitu.cn/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $API_KEY" \
  -d '{"model":"<模型ID>","messages":[{"role":"user","content":"你好,请介绍一下平台能力"}],"temperature":0.7}'
```
model 是模型 ID,messages 是消息数组,role 可为 user/assistant/system。原文 temperature 范围为 0-2;具体模型支持的参数与范围以模型文档为准。

# 4.12 调用报错如何排查?常见错误码含义?

知识ID:KB-c57408d608e0
产品:SmartTITU
版本:2026-10-08 v1
适用对象:customer
状态:source_based
来源:7.SmartTITU销售常见问题速查FAQ-20261008v1.pdf | PDF物理页:8

400:请求参数错误或能力不支持;检查请求体、model ID,确认模型是否支持 function calling。
401:鉴权失败;核对密钥状态、模型/IP 白名单与 Authorization 请求头(Bearer sk-xxx)。
403:权限不足;检查模型或接口权限、来源 IP 白名单。
404:资源不存在;检查 model ID 与请求路径。
429:触发 RPM/TPM 限流;降低调用频率、错峰或申请扩容。
500/503:平台或上游临时故障;稍后重试。503 可能表示无可用推理渠道,持续出现请提供 Request ID 联系客户经理。
504/超时:检查网络、缩短输入或重试。
