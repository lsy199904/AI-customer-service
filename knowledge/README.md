# 本包知识说明

本包保留134条客户知识：产品体系7条、销售FAQ28条、Hub操作手册7条、AI Token术语92条。运行数据在 `../data/knowledge.jsonl`，本目录4份Markdown是可读快照，可单独用于Dify导入预览。

每条记录含id、标题、正文、产品、版本、原文件名和PDF物理页码。HTML术语没有物理页码。Markdown内的`<<<KB_SPLIT>>>`用于区分完整条目。

两份飞书快捷方式没有本地正文，未获取或转录。安全审计历史样例、AICC图文资料、Edge管理员手册、内部销售话术和待确认安全承诺没有进入当前客户检索数据。口径冲突与待补充清单中提到的管理员/参考目录属于原知识整理包，不代表本代码包包含这些目录。

本目录的来源清单记录原始本地材料的名称及哈希，原PDF没有打入代码包。来源接口返回已整理条目，不会自动提供原PDF下载。需公开原文档时先部署符合授权范围的文档，再配置SOURCE_BASE_URL。

修改Markdown不会自动更新运行数据；知识维护请同步更新JSONL，保留来源字段并审核适用范围。更新后重启服务，并运行`python3 scripts/build_prototype.py`重建独立原型。当前资料没有经过线上产品状态实时核验。
