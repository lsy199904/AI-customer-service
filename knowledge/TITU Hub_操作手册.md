# 一、快速使用检查清单总结

知识ID:KB-1f1ccd22e9f9
产品:TITU Hub
版本:V1.1 / 2026-10
适用对象:customer
状态:source_based
来源:11.TITU Hub用户操作手册-20261009.pdf | PDF物理页:3

拿到账号后,按顺序完成以下步骤即可开始调用:
1. 登录控制台,自助或线下订购套餐,确认状态为「生效中」
2. 进入模型广场,浏览所需模型及 model ID
3. 创建 API 密钥(配置名称、可选 IP 白名单、模型白名单)
4. 使用密钥与 model ID 发起调用(兼容 OpenAI 协议)
5. 在用量统计中确认调用成功,并关注账单与安全审计报告
口径说明:本手册第4页对各套餐均描述线下开通,与本段“自助或线下”不完全一致。当前办理请优先联系客户经理/运营确认,不要承诺已支持自助订购。

# 四、API 密钥管理

知识ID:KB-0704c5203cb1
产品:TITU Hub
版本:V1.1 / 2026-10
适用对象:customer
状态:source_based
来源:11.TITU Hub用户操作手册-20261009.pdf | PDF物理页:5

路径:左侧导航 → 服务 → API密钥
API 密钥是调用平台接口的身份凭证(以 sk- 开头)。在本页可创建、查看和管理密钥。
创建时页面会引导配置:密钥名称、IP 调用白名单(可选)、模型调用白名单(建议按最小权限勾选);具体选项与规则以页面提示为准。
创建成功后请妥善保存密钥,密钥仅显示一次。
