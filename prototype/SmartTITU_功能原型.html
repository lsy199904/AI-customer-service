SMARTTITU / CUSTOMER ASSISTANT / MVP 1.0

如何体验真实后端？

解压代码包，在项目根目录运行 python3 manage.py init，再执行 python3 manage.py serve。浏览器访问 http://127.0.0.1:8000/widget/demo，使用 python3 manage.py token --tenant demo --user tester 生成的短期凭证连接。

真实服务会把历史写入 SQLite；配置 ANSWER_MODE=llm 及模型地址、密钥、模型 ID 后才会调用大模型。详细部署步骤以代码包 README 为准。
