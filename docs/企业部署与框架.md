# 企业客服框架与部署

当前后端使用FastAPI、Uvicorn和LangChain Core。浮窗及iframe只是展示和嵌入入口，统一调用同一后端。

## 请求流程

企业页面获取当前登录人的短期凭证 → 浮窗或iframe发送Bearer请求 → FastAPI校验身份、来源、请求大小及字段 → 按企业和用户读取会话历史 → 意图分流 → LangChain检索链 → BGE-M3向量召回和Reranker排序 → LangChain提示及生成链 → 引用和图片ID校验 → SQLite保存消息与来源 → 返回回答。

问候不进行知识检索。没有有效证据时引导人工，避免模型补写业务事实。实际配置二维码为空时不显示二维码。检索器输出LangChain Document，来源、页码及配图ID保留在metadata；每个请求持有独立检索报告。LangChain生成链通过ChatPromptTemplate和MessagesPlaceholder组装系统提示、最近12条历史及当前证据，再调用已有受控模型客户端，最后校验引用。调用链明确禁用LangSmith外传追踪。

## 服务运行

生产入口仍是 `python -m app.server`，内部运行Uvicorn；管理入口 `python manage.py serve` 会先读取.env再启动。FastAPI在lifespan中创建并关闭Service及数据库连接。接口为同步def，阻塞的Embedding、重排、模型HTTP和SQLite操作在线程池执行；事件循环仍可处理健康检查。原业务Service保留，避免框架迁移改变知识版本或会话数据。

服务固定单worker：最多32个应用并发请求，超出时返回503；会话冲突返回409，用户限流返回429。Uvicorn外层连接并发上限64。优雅退出最多等待180秒，Compose stop_grace_period为190秒；不再强制10秒终止仍在生成的回答。现有会话锁是进程内锁，不能通过增加workers直接扩容。

## 接口与可观察性

- GET或HEAD /health：进程存活，不调用模型。
- GET /ready：应用和会话数据库可用，不代表上游模型或答案质量通过验收。
- GET /openapi.json：需要Bearer凭证的OpenAPI规范，包含Pydantic请求模型及HTTPBearer安全方案。
- 原有/v1/bootstrap、sessions、messages、sources及版本文档下载保持路径和JSON响应兼容。
- HTML、脚本、图片使用固定白名单，HEAD静态请求也可返回200；不开放目录浏览。
- X-Request-ID出现在响应中；可在日志中定位服务异常，不记录Authorization、问题正文、URL查询参数或模型报错详情。
- POST仅接受application/json，最大16384字节；提前检查声明长度和实际接收大小。输入校验失败维持400错误结构。
- FRAME_ORIGINS控制iframe父页面，CORS_ORIGINS控制浏览器API来源；企业与用户身份仍来自后端签名凭证。

## 当前服务器升级

```bash
cd ~/ai_customer
git pull --ff-only origin main
# 在旧服务仍运行时先备份现有会话与知识数据库
sh scripts/docker-host.sh exec assistant python manage.py backup
# 新增框架依赖，必须构建新镜像
sh scripts/docker-host.sh build assistant
sh scripts/docker-host.sh up -d --force-recreate assistant
sh scripts/docker-host.sh exec assistant python manage.py check
curl --max-time 10 http://127.0.0.1:8000/ready
```

执行build成功后再up；仅restart不会在旧镜像里安装依赖。models、knowledge_sources、var、.env继续原目录挂载，不删除或改名，不重新下载模型。本次保持原索引指纹，默认71条知识继续可用，不用重新入库。代码更新不上传你的Word和原始PDF；配图按已发布登记表继续使用。

安装通过requirements.lock锁定版本，requirements.txt列出直接依赖范围。使用Python3.12。开发环境安装 `python -m pip install -r requirements-dev.txt`。当前已在本机运行实际FastAPI TestClient与Uvicorn HTTP集成测试，模型使用可控替身；Docker与Linux上的真实模型仍须按服务器输出验收。

## 运行边界

这是可部署的单实例企业客服基础版，保留SQLite会话与向量持久化。知识内容是已认证客户共享的外部资料，不提供各企业私有知识的权限分区。业务登录接口仍由现有平台后端实现；不要把AUTH_SECRET交给浏览器。后续需要多实例、高可用或大规模向量检索时，再迁移到共享数据库、分布式会话锁与相应向量存储，不能仅改workers数量。
