# 企业服务SOP流程统一

2026年11月4日依据《SMARTTITU企业服务门户操作指引（SOP）V1.0》统一客户开通流程。运营门户内部操作不纳入本次修改。

## 客户办理口径

- 问题4注册：手机号、短信验证码、密码和确认密码，邮箱选填，同意协议后注册，成功跳转登录页。
- 问题5登录：手机号短信验证码或手机号密码登录，成功进入总览。删除旧邮箱验证码、旧ESP账号登录方式；不将e签宝授权登录混作门户登录。
- 问题6认证：企业管理编辑并保存企业名称、统一社会信用代码和公司地址，去认证进入e签宝，授权实名后等待企业管理员审批，以门户显示已认证为完成。删除CRM和内部风险核查等客户无需操作的分支。
- 问题7签约：完成企业认证，签约管理新增签约，核对甲方、乙方、模板和经办人手机号后发起，在e签宝签署。合同完成与服务订购生效分别说明，失败按提示处理重试，不自动转为线下签约。
- 问题8与40订购：企业认证及签约均完成后，选择套餐、供应商、模型、可选增值服务并提交，在我的服务核对生效状态。保留一次仅能订购一个服务的限制及异常联系说明。
- 问题9只修正签约与订购顺序，保留默认星级和28日前后权益生效日期规则。
- 问题310修正发起失败处理完成标志，不再错误继承合同最终已完成状态。

重复问题348、351、352分别合并到4、7、8，未重排其他编号。问题308的短信找回密码说明已正确，不重复加入原SOP的垃圾邮件箱笔误；创建API Key保留企业认证、签约、订购前置条件。
