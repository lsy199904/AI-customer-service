# PDF 主题切分与来源展示

本次替换按物理页创建章节的 PDF 解析策略。Word 内容及原始 PDF 文件不变，既有混合召回、重排门槛、身份认证、会话隔离、最多三条辅助证据不变。

## PDF 解析

优先使用 PDF 目录、字号提示、编号章节和短标题建立主题。一个主题可以连续跨页，一页也可以包含多个主题。没有可靠标题时，保留正文、按段落和长度切分，不虚构业务分类。长主题继续使用长度和重叠切分，页码按实际片段交集记录。

公众号打印页的时间页眉、原文网址页脚、页码、往期推荐、视频播放时长等不再进入答案证据。原文链接转为来源元数据，业务正文保留。扫描件仍需先 OCR；视频和图片内容不会自动转成正文。

主题元数据包括 section_title、document_title、source_kind、recommended_question 和 retrieval_context。检索上下文仅引用原文主题及关键词、适配用户、核心能力等原文行，不生成新的事实或宣传承诺。

PDF 使用独立解析版本；增量 ingest 会重新解析已入库 PDF，替换活动版本，保留旧修订供历史引用。Word 的修订计算和 Embedding 配置指纹不变，未修改 Word 跳过，不需要全量 rebuild。

## 检索与推荐

词法通道去掉“我们要求”“适合用哪种服务”等通用提问外壳，避免这些词稀释关键词覆盖度。原问题仍完整传给向量模型、重排和生成模型。没有添加针对数据不出域、信创或某个产品的固定答案，没有降低相似度和重排门槛。

自然问题推荐替代 PDF 文件名和页码。推荐绑定仍按活动知识 ID 与修订核验，更新或停用文档后旧推荐不能重新激活旧知识。无法确定唯一来源时不强行绑定。遗留的 PDF 页码占位标题不再作为推荐。

生成提示补充：兼容性、认证等结论须由直接证据支持；分类问题遵循原文分类，不把其他章节的功能拼成新分类。提示词不能保证真实模型永不出错，仍保留原后台依据告警。

事实性的能力确认和分类咨询默认不配图；明确要求看图、完整步骤等仍由现有独立图片策略处理。并行配图、增量流式、来源提前展示和图片等待上限不变。

## 部署

```sh
cd ~/ai_customer/ai_customer_v3

git pull --ff-only origin v3 &&
sh scripts/v3.sh ingest &&
sh scripts/v3.sh start &&
sh scripts/v3.sh check &&
sh scripts/v3.sh doctor
```

本次必须执行增量 ingest，把旧 PDF 页片段替换为主题片段。不要只重启，也不必加 --rebuild。保留全部活动源文件的原路径；现有 PostgreSQL、Milvus、模型和 .env 配置不变。代码目录挂载的 v3 不需重建镜像。最后刷新页面并新建会话验证，避免把旧历史回复误当作新结果。

最终回归共 318 项，310 项通过、8 项因私有附件或外部数据库条件跳过。前端主题来源、历史引用序列化和链接渲染测试通过；原始 Word/PDF 文件未修改。新主题规则会影响之后所有文字型 PDF 的解析，不局限于本批公众号资料。
