# 一段脚本加载完整悬浮客服

## 交付方式

客服服务同时提供后端接口和widget.js。这个脚本会自动在业务页面右下角创建按钮,点击后展示完整聊天窗口。窗口、消息、来源详情、人工联系信息等全部由组件负责,业务前端不用再制作聊天窗口。

使用标准浏览器HTML/JavaScript显示界面,并非后端进程可以直接绘制浏览器窗口。业务页面需要加载组件;如果不希望修改业务页面源代码,可由现有门户公共布局或反向代理统一注入脚本。当前项目提供脚本,没有擅自修改现有门户或代理配置。

## 三步接入

1. 部署客服服务,在.env设置模型、CORS_ORIGINS和联系方式。
2. 在现有控制台后端提供已登录用户的短期客服凭证接口。
3. 在业务页面公共布局加载下方脚本,不用再写聊天UI。

```html
<script src="https://assistant.example.com/widget.js"
        data-auth-url="/api/assistant/token" defer></script>
```

这里的域名为示例,部署时替换。apiBase默认取脚本来源域名;若API有代理前缀,可另加`data-api-base="https://portal.example.com/assistant"`,该地址应直接承接`/v1/...`接口。

凭证接口默认`/api/assistant/token`,必须与业务页面同源,通过已有控制台登录Cookie识别企业和用户。返回JSON `{"token":"短期签名凭证"}`并设置Cache-Control:no-store。实现时在可信控制台后端使用issue_token,共享AUTH_SECRET仅保留在两个可信后端中。不能让浏览器传任意企业ID来换取凭证,不能把AUTH_SECRET或MODEL_API_KEY嵌入脚本。

此接口是现有登录系统的适配工作,当前未提供你们控制台的代码,所以尚未在真实登录系统内实现。没有这个接口时可先使用本地演示页,手动粘贴测试凭证验证。

## 页面已有其他凭证机制时

也可以由页面初始化时传入异步凭证函数:

```js
window.SmartTITUAssistant.configure({
  apiBase: 'https://assistant.example.com',
  getToken: async () => {
    const r = await fetch('/api/assistant/token', {credentials:'same-origin'});
    if (!r.ok) throw new Error('请先登录');
    return (await r.json()).token;
  }
});
```

调用前须确认widget.js已经加载。脚本采用内存状态,不把凭证或消息写入localStorage。每次展开重新获取身份与本人历史。当前窗口打开时若主站切换账号或退出登录,主站须调用`SmartTITUAssistant.reset()`清除窗口内容,避免旧账号消息仍显示。

可用方法:

- open():打开窗口并加载本人最近会话。
- close():收起窗口,不删除后端消息。
- reset():终止当前请求、清理浏览器内存状态并收起;用于退出或切换账号。
- configure(options):更新apiBase/getToken/tokenEndpoint,同时清理旧状态。
- destroy():卸载悬浮组件。

## 已包含的交互

欢迎语、快捷气泡、输入发送、中文输入法Enter处理、Shift+Enter换行、等待状态、失败重试、来源详情、人工联系卡片、已配置二维码、创建会话、本人会话列表、历史恢复、历史分页与删除确认。删除按钮先显示“确认删除”,再次点击才调用后端删除。界面展示纯文本,不执行模型或知识正文中的HTML。

30分钟无键盘或指针操作自动收起。窗口采用Shadow DOM隔离常见页面样式,移动端自动调整宽度。没有使用前端框架、CDN、图标库或外部字体。极端全局!important规则、宿主页面CSP限制仍需实际业务页面检查。

## 部署注意

HTTPS页面应加载HTTPS脚本。跨域问答时,在客服服务配置精确CORS_ORIGINS。若主站有严格CSP,需允许客服服务域名的script-src与connect-src,组件样式使用Shadow DOM内的style标签,应与主站样式策略协调;二维码域名需符合img-src。默认不会打开第三方业务页或发送数据到其他统计服务。

默认AI模式仍为extractive,会明确显示“知识原文摘录”。真实大模型回答需要配置llm模式和可用模型密钥。二维码未配置时只显示电话和邮箱,不会虚构“人工已接入”。
