# 独立演示候选版本

分支 v3-answer-image-focus；基线 0e5bcff。不更新v3，不修改知识库、检索、阈值、认证或会话隔离。

改动：生成提示只要求回答本轮所问，保留适用对象，不把方式咨询扩展为完整流程。已有图片语义规划增加request_kind；规则、方式、普通介绍和局部追问类型即使提议流程图，也统一禁止配图。明确看图和完整流程仍使用原有选择、去重和来源机制。不增加模型调用，不改变流式和持久化。

新语义字段兼容原有规划接口。实际模型仍可能错误分类，控制测试不代表真实模型问法100%成功；需在演示前抽测用户截图问法及其改写。

无需重新入库或重建镜像。部署前记录当前提交和分支；在实际v3目录fetch新分支、切换后执行v3.sh start/check。该操作会重建应用容器，有短暂停顿。若临近演示且无时间抽测，保留当前版本。

回退到记录的原提交，执行同样start/check即可。切换前要求工作区干净，不使用reset --hard。
